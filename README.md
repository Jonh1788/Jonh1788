## 👨‍💻 Sobre mim

Sou **Engenheiro de Software Full Stack e DevOps**, focado em construir aplicações web e mobile, APIs, automações e fluxos de entrega confiáveis.

- 🚀 Desenvolvimento de produtos com **TypeScript, React, Next.js, Node.js, PHP e Laravel**
- 📱 Aplicações multiplataforma com **Flutter e Dart**
- 🗄️ Bancos de dados **PostgreSQL, MySQL e SQL**
- ☁️ Práticas de **DevOps, Docker, Linux, CI/CD e Cloudflare Workers**
- 🤖 Uso de **Claude e IA generativa** para análise, implementação, depuração e documentação
- 🧩 Interesse em **SaaS, sistemas distribuídos, tempo real, segurança e escalabilidade**
- 🌎 Itabuna, Bahia, Brasil — aberto a oportunidades remotas
